# 隐私与安全

## 本机数据

胶囊坞默认在 `%APPDATA%\CapsuleDock` 保存用户设置、待办、置物文件路径等运行数据。环境变量 `CAPSULEDOCK_DATA_DIR` 可指定另一目录。置物架保存原文件路径，不复制文件正文。

## 网络访问

音乐兼容功能会只读访问汽水音乐、酷狗音乐的本机歌词缓存，以及网易云音乐的本机播放日志和播放队列；酷狗配置仅用于提取歌词目录。只保留歌词、歌曲 ID、歌名、歌手、专辑、公开封面地址、播放状态和时间轴，缺少系统封面时会从网易云图片服务获取专辑缩略图。日志正文、音频签名链接等内容不会保存或上传。网易云原生播放事件不依赖 SMTC 或固定内存地址；必要时仍可对已匹配的网易云、酷狗版本只读获取播放进度。不会修改播放器、读取音频或提取登录信息。启动或运行异常的诊断日志保存在数据目录的 `diagnostics/last-error.log`，不会自动上传。

启用歌词功能后，程序会访问公开的歌词服务用于匹配；连接方式见源码中的 `lyrics.rs` 及对应 provider 模块。

点击「检查更新」时，程序会访问 GitHub 的公开发布接口，并在请求头中包含胶囊坞版本号，不发送本地设置或其他个人数据。选择「下载并安装」会从 GitHub 下载公开安装包至 `%LOCALAPPDATA%\CapsuleDock\Updates`，核对大小及 SHA-256 后替换程序并重启；「浏览器下载」通过默认浏览器打开发布页。

程序不使用统一的胶囊坞云端账号。第三方服务自身的数据处理政策仍然适用。

## 登录凭据

不要把 Cookie、授权码、凭据文件或私人数据提交到 GitHub。

## 反馈安全问题

请使用仓库的私密漏洞报告入口，见 [SECURITY.md](../SECURITY.md)。普通 UI 问题可以开公开 Issue，但请先去除敏感信息。

# 使用指南

## 第一次打开

鼠标靠近屏幕顶部的小坞会展开功能面板。左右箭头和底部圆点切换页面；在列表内部滚轮查看更多内容。托盘菜单可打开设置、控制开机启动或退出程序。

设置里的功能显示开关可以隐藏不常用的页面；隐藏页面不等于删除它的数据。

## 音乐、专注与待办

音乐来自 Windows 媒体会话，播放器需要提供系统媒体信息。歌词匹配依赖歌曲元数据和外部服务，个别版本、纯音乐或未找到歌词的歌曲可能无法显示同步歌词。

专注与休息需点击开始，结束后可进入下一阶段。待办提醒是可选项，填写任务后通过日期／时间选择器设置，不需要手写时间格式。

## 更新、卸载与数据目录

双击新版 `CapsuleDock-Setup-v版本号-x64.exe`，可通过路径输入框或「浏览…」选择安装文件夹，勾选「创建桌面快捷方式」和「开机自启」，再点击「一键安装」。首次安装默认创建桌面快捷方式、不开机自启；升级默认保留现有选择。安装位置默认为 `%LOCALAPPDATA%\Programs\CapsuleDock`，可改为其他有写入权限的文件夹，用户数据仍保存在 `%APPDATA%\CapsuleDock`。

升级安装保留数据。若提示胶囊坞正在运行，先从托盘退出，再点击重试。

在 Windows 已安装应用中卸载会移除程序和快捷方式，但保留数据。

## 常见问题

**窗口没有出现：** 检查托盘是否已有实例、是否在全屏应用中、设置是否启用了全屏隐藏。

**图标或布局异常：** 反馈 Windows 版本、屏幕缩放比例、显示器数量和截图。截图先遮挡账号、验证码。

胶囊坞常驻在屏幕边缘，鼠标靠近时展开成功能面板，收起时只剩一条刘海或胶囊。音乐控制、专注计时、置物架、待办提醒与系统状态都在同一个坞里，配合桌面吉祥物和系统级实时毛玻璃，不占桌面空间。

当前版本：**1.0.0**（首个正式版）。完整的功能细节见 [CHANGELOG.md](CHANGELOG.md)。

## 功能

### 灵动坞

| 能力 | 说明 |
| --- | --- |
| 收起与展开 | 常驻屏幕边缘，鼠标靠近自动展开，离开后收回；收起态是刘海或胶囊 |
| 三种停靠 | 顶部、左侧、右侧；左右停靠时收起为竖向胶囊，组件竖排 |
| 两种形状 | 刘海、胶囊 |
| 大小调节 | 80%–140%，文字、图标、吉祥物按实际像素重绘，放大不发虚 |
| 位置调节 | 拖动滑块或微调按钮移动，一键恢复居中；左右停靠时表示上下位置 |
| 极简刘海 | 收起时只显示一条细线 |
| 多显示器 | 在设置里指定坞所在的显示器；把坞从边缘拖离时暂时回到主屏 |
| 全屏隐藏 | 游戏、视频等全屏应用在前台时自动隐藏 |
| 自动避让 | 指定应用盖住坞所在的边缘时收成贴边细线；可自动识别 Chrome、Edge、夸克等常用浏览器，也可自行添加应用 |
| 实时毛玻璃 | 毛玻璃皮肤使用 Windows 合成引擎的系统级模糊，严格贴合坞体轮廓（需系统开启「透明效果」）；关闭后改为烟熏半透明 |

### 外观与皮肤

皮肤与形状相互独立，可任意组合：

| 皮肤 | 特点 |
| --- | --- |
| **经典** | 纯黑坞体，与屏幕刘海融为一体，资源占用最低 |
| **奶油** | 暖白底色、深棕文字与橙色强调，柔和明亮 |
| **毛玻璃·浅** | 浅色磨砂玻璃，透出身后桌面的颜色，深色文字；按背景明暗自动调整，保证清晰 |
| **毛玻璃·深** | 深色玻璃，黑底白字，更通透 |
| **悬浮云** | 半透明灰底随音乐封面换色，光晕跟随鼠标，播放进度带渐隐光尾（皮肤作者：啵 / @hanhb123） |

设置页本身也支持跟随系统 / 浅色 / 深色三种主题。

### 功能页面

展开后通过左右箭头或底部圆点切页；顺序可在设置里拖动调整，也可单独隐藏（隐藏只影响显示，数据与提醒设置保留）。

| 页面 | 功能 |
| --- | --- |
| **音乐** | 播放 / 暂停、上一首 / 下一首、可拖动的进度条；显示专辑封面；逐句高亮的同步歌词。来源为本机媒体会话，兼容网易云音乐、酷狗音乐、汽水音乐、QQ 音乐等播放器 |
| **专注** | 番茄钟式计时，专注结束自动进入休息并可循环；专注 1–180 分钟、休息 1–60 分钟可调；坞内显示进度，阶段切换时提醒 |
| **置物架** | 把常用文件拖到坞上即可收藏（只保存路径，不复制文件正文）；「剪贴板」分栏记录最近 30 条复制内容（另可固定最多 20 条），点一下即可再次复制，历史保存在本机；密码管理器标记为敏感的内容不记录 |
| **待办** | 任务添加、编辑、完成、删除；到点提醒并可从通知直接定位到对应任务；支持按周一到周日的任意几天每周重复，重复任务当天出现并提醒、次日重置为未完成，不在今天的重复任务排在末尾并变暗 |

### 收起时的常驻组件

顺序可在设置里拖动排列，可单独开关：

| 组件 | 说明 |
| --- | --- |
| 时钟 | 时间与日期，可选 12 / 24 小时制，时段文字可选「不显示 / 上午下午 / 详细时段」 |
| 电量 | 本机电量与充电状态；无电池设备自动隐藏 |
| 电脑状态 | CPU / 内存双圆环，按阈值配色：<60% 绿、60–85% 琥珀、>85% 红 |
| 音乐 | 正在播放的指示 |
| 专注 | 专注计时进度 |
| 铃铛 | 通知入口，有待办提醒时高亮，点击进入待办页 |
| 吉祥物 | 桌面宠物，播放音乐时一起唱歌，专注、困倦、睡觉时各有表情 |

另外支持「坞上歌词」：收起时在坞上显示正在唱的那一句（仅顶部停靠）。

### 提醒与通知

- **待办到点**：在坞上弹出提醒，并定位到对应任务。
- **专注计时**：专注 / 休息阶段切换提示。
- **蓝牙设备**：设备连接、断开的提醒（可在设置中关闭）。
- **系统状态**：音量、大写锁定、键盘输入语言、网络连接、电源变化。
- **提醒声音**：待办与专注提醒可开启提示音（默认关闭）。

### 托盘与系统集成

托盘菜单包含：开机启动、吉祥物、极简刘海、设置…、关于胶囊坞、退出。

- **开机自启**：登录 Windows 时自动启动，可在托盘或设置里切换。
- **单实例**：重复启动不会开第二个坞，只唤起设置窗口。
- **应用内更新**：访问 GitHub Releases，校验安装包 SHA-256 后替换并重启。
- **诊断日志**：启动或运行异常写入 `%APPDATA%\CapsuleDock\diagnostics\last-error.log`，不自动上传。

### 设置

从面板、托盘或应用内入口打开，分组如下：

| 分组 | 主要选项 |
| --- | --- |
| **常规** | 设置页主题（跟随系统 / 浅色 / 深色）、开机启动、皮肤、形状、大小、显示器、停靠位置、水平位置、背景模糊、极简刘海、全屏隐藏、吉祥物 |
| **页面管理** | 常驻组件的排列与开关、功能页面的排序与显隐 |
| **音乐与歌词** | 歌词开关、坞上歌词、歌词显示时间偏移 |
| **专注** | 专注与休息时长 |
| **待办与置物** | 待办清单、置物架、剪贴板记录开关 |
| **通知** | 系统状态提示、蓝牙通知、胶囊坞提醒（待办 / 专注提醒总开关）、提醒声音 |
| **关于** | 版本号、检查更新、打开本地数据目录、第三方图标归属 |

## 安装

### 系统要求

- Windows 10 / Windows 11（64 位）
- 毛玻璃皮肤需要系统「设置 → 个性化 → 颜色 → 透明效果」处于开启状态

### 下载安装包

1. 前往 [Releases](https://github.com/qbbyte/capsuleDock/releases) 下载最新版 `CapsuleDock-Setup-v版本号-x64.exe`。
2. 双击运行，可选择安装位置、是否创建桌面快捷方式、是否开机自启。
3. 默认安装到 `%LOCALAPPDATA%\Programs\CapsuleDock`，用户数据保存在 `%APPDATA%\CapsuleDock`。
4. 升级时直接运行新版安装包，覆盖安装并保留设置和数据。

### 卸载

在 Windows「已安装的应用」中卸载，会移除程序和快捷方式，但保留用户数据目录。

## 数据目录

| 内容 | 默认位置 |
| --- | --- |
| 设置、待办、置物架路径、剪贴板历史 | `%APPDATA%\CapsuleDock` |
| 诊断日志 | `%APPDATA%\CapsuleDock\diagnostics\last-error.log` |
| 更新下载缓存 | `%LOCALAPPDATA%\CapsuleDock\Updates` |

可用环境变量 `CAPSULEDOCK_DATA_DIR` 指定其他数据目录（开发时建议指到临时目录，避免覆盖日常数据）。

## 从源码构建

### 依赖

- Rust stable
- Visual Studio C++ 构建工具（MSVC 链接器）
- Windows SDK（提供 `rc.exe`，用于把图标和版本信息编进 exe）

### 编译与运行

```powershell
cargo build --locked --bin capsuledock
```

启动：

```powershell
cargo run --locked --bin capsuledock
```

`cargo run` 默认使用 debug 构建，改完源码直接重跑即可；需要接近发布版的性能时用 `cargo run --release --locked --bin capsuledock`。

如果笔记本接扩展坞或外接显示器时提示 OpenGL 不可用，胶囊坞会自动改用 Direct3D 12 启动。

### 演示录制器

无窗口的演示录制器 `capsuledock-record` 使用合成数据和软件光栅化，需要 `record` feature：

```powershell
cargo run --locked --features record --bin capsuledock-record
```

### 打包

打包脚本使用 NSIS 生成安装包：

```powershell
./scripts/package.ps1
```

首次使用需先通过 `./scripts/get-nsis.ps1` 获取 NSIS 编译器；版本号取自 `Cargo.toml`，并与 exe 的 `FileVersion` 校验一致。

## 开发

运行测试：

```powershell
cargo test --locked --all-targets --features record -- --test-threads=1
```

常规测试使用合成数据；个别标记为 `#[ignore]` 的测试依赖特定系统环境，按需显式运行。

## 隐私

- 胶囊坞默认在 `%APPDATA%\CapsuleDock` 保存用户设置与运行数据，不使用统一云端账号。
- 音乐歌词功能会读取本机播放器（网易云、酷狗、汽水）的缓存与播放日志，只保留歌词和歌曲元数据，不保存或上传日志正文、音频内容或登录信息。
- 检查更新时只访问 GitHub 公开发布接口并在请求头中包含版本号，不发送本地设置或个人数据。
- 诊断日志保存在本机，不会自动上传。

发现安全问题请通过 GitHub 的私密漏洞报告入口反馈，不要在公开 Issue 中附带凭据或账号数据。详见 [SECURITY.md](SECURITY.md)。

## 常见问题

**毛玻璃皮肤看起来是半透明而不是模糊？**
检查系统「透明效果」是否开启；部分虚拟机和远程桌面环境不提供合成模糊，此时会自动退化为烟熏半透明。

**坞没有出现，或者被其他窗口挡住？**
确认「全屏隐藏」与「自动避让」的设置；坞会避让盖住边缘的全屏应用和指定程序。托盘菜单可以随时打开设置或退出。

**歌词不显示？**
确认播放器正在播放且被系统媒体会话识别；歌词来源为本机缓存与播放日志，显示时间可在设置里整体偏移。

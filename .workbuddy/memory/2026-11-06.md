# 2026-11-06

## 新增功能：岛内 CPU / 内存双圆环（电脑状态）
- 用户希望岛上常驻显示 CPU 和内存占用，做成**圆环**（圆心两位数字 + 阈值配色：绿<60% / 琥珀 60–85% / 红>85%），而非纯文字。
- 落地改动：
  - 新增 `src/sysmon.rs`：用 `windows` crate 的 `GlobalMemoryStatusEx`(dwMemoryLoad) 取内存、`GetSystemTimes` 两次差值取 CPU；约每秒采样一次（`PollClock` 节奏器），首帧 CPU=0。
  - `src/bar_layout.rs`：新增 `SYSMON` 槽位（常量=6、WIDTHS 加 36.0），`Layout::new` 加 `sysmon: bool` 形参，放在时钟之后；`DEFAULT_ORDER` 与 `valid_order` 改为 6 位；5 处测试里的自定义顺序同步补成 6 位。
  - `src/model.rs`：新增 `show_sysmon: bool`（默认 true），load/save + `resident_order` 旧 5 位顺序迁移（自动补 SYSMON 到时钟后）。
  - `src/app.rs`：`sysmon` 字段 + `cpu_shown`/`mem_shown` 平滑显示值；`tick()` 里每秒采样并 lerp；`shared_header()` 在时钟/日期后绘制双圆环（`draw_sysmon` + `sysmon_color`）。
  - `src/extras.rs`：设置页「状态组件」卡片加「电脑状态」开关（`show_sysmon`）。
  - `src/resident_settings.rs`：`preview_layout` 加 sysmon 形参与默认顺序。
- 验证：`cargo check --bin capsuledock` 与 `cargo check --tests` 均零错误（仅增量锁文件的良性告警）。未做 GUI 实跑（无显示器），需本地 `cargo run` 看效果。
- 设计细节（圆环直径 6.5、间距、配色）均为首版取值，可按截图反馈再调。
